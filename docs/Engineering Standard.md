# Ankesh's Writting | Engineering Standards

Version: 1

## List of Standards

- Process Standard: Defines ***how software is developed and managed.***
- Product (Quality) Standard: Define ***what quality the software must achieve***
- Coding Standard: Rules for ***writing clean, readable, and maintainable code***
- Design Standard: Ensure software design is ***modular, reusable, and scalable***
- Documentation Standard: Define ***how software documents should be written***
- Testing Standard: Ensure software is ***verified and validated properly***
- Security Standard: Protect software from vulnerabilities and attacks
- Configuration & Change Management Standards: Control ***versions, changes, and releases***
