# Notes Management system

Notes management system intended to provide ability to manage(read, write, draft, publish) notes. It'll provide categorized view of notes.

## Requirements

### Home (/)

Show catogries/ names of notebooks/articles.

### Topics Listing (/{topic}/)

Show list of all the topics published under that catagory.

### Details (/{topic}/{chapter1})

Show content of topic.

### Additional Requirement

Search tool to search topics/notebooks/articles.
